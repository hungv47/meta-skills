## Vision

Collapse the 4 separate plugins (`research-skills`, `marketing-skills`, `product-skills`, `meta-skills`) into a single `meta-skills` plugin carrying all 35 skills.

- **Why:** the per-stack boundary was organizational, not technical. Real friction: triple-bump dance, 4 fragmented CHANGELOGs, hard cross-stack edits. Users already on `meta-skills` like the install and only want one — folding the others in is the discovery vector.
- **Naming call:** keep `meta-skills` as the install name (users already trust it) but rebrand the *meaning* from "process-layer skills" to "meta-package of all skills." Existing meta skills sit under `skills/meta/` as siblings to the others.
- **Decisions locked (2026-05-19):**
  - Archive the 3 retired plugin repos + the `agent-skills` umbrella (do not delete).
  - Merge all 4 CHANGELOGs into `meta-skills/CHANGELOG.md` with `[meta]` / `[research]` / `[marketing]` / `[product]` prefixes.
  - `_biz-ops/` stays at `biz/` root (already there, no move).
  - `autoresearch/` extracts to `biz/autoresearch/` (NOT into meta-skills) — deferred to Phase 6.
  - Per-stack `shared/` files (`hypothesis-framework.md`, `marketing-foundations.md`) land stack-scoped at `skills/{stack}/_shared/`.
  - Same-day archive after deprecation notices land (no soak period — solo-operator stack).
