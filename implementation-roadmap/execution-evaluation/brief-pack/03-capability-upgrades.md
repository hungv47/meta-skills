# Brief 03 — Capability Upgrades

## Goal

Upgrade the quality of specialist skills without letting methodology work block the core architecture. These changes make outputs sharper, but they should land after `/forsvn`, state, and naming decisions are stable.

## Copy and Ads

Upgrade copy skills around construction, not just critique.

Copywriting upgrades:
- require Unique Mechanism before writing
- support 6 Necessary Beliefs as an alternate body architecture
- treat hooks as the first premise of an argument, not clever phrasing
- add Discovery Story as a social proof pattern
- add Seven Sweeps as a post-generation editing mode

Ad-copy upgrades:
- model Meta's filtering path: Retrieval → Light Ranking → Heavy Ranking → Auction
- use Message Transmutation: AI UGC, Native Static, AI Animation
- support advertorial pre-lander / Chad Funnel structures
- add AI UGC VSSL narrative pattern
- use Contrast Principle against competitor hooks
- recommend Variable Subtraction when test results are ambiguous

Shared research workflow:
1. Research doc
2. Avatar and offer brief
3. Belief engineering
4. Unique Mechanism

## Research Rigor

Upgrade ICP/customer research:
- confidence labels on every finding: High, Medium, Low
- rationale based on source count and consistency
- Digital Watering Hole source guide by market type
- sample-bias checks
- minimum viable sample: avoid conclusions from fewer than 5 independent data points per segment

## SEO and AI Visibility

Add AI search visibility as a distinct capability.

AI SEO should cover:
- extractable content blocks
- citable authority signals
- bot-by-bot robots.txt analysis
- `/pricing.md`
- `/docs/llms.txt`
- structured data
- query × platform visibility matrix

Programmatic SEO should cover:
- templates
- curation
- conversions
- comparisons
- examples
- locations
- personas
- integrations
- glossary
- translations
- directories
- profiles

Prefer a distinct AI SEO skill if the user wants clean methodology. Add programmatic SEO inside existing SEO unless the user wants a larger surface.

## Humanmaxxing

Replace or evolve `humanize` into a sharper writing transformation skill.

Desired behavior:
- compress aggressively
- remove generic corporate polish
- allow small human imperfections when appropriate
- avoid em dashes
- vary rhythm and register
- preserve concrete details
- avoid AI-tell words like `utilize`, `leverage`, `delve`, `testament`

This is not synonym swapping. It must restructure meaning and flow when needed.

## Platform-Specific Strategy

Generic social advice is too weak. Platform skills should consume platform-specific research.

Required platform briefs:
- X/Twitter: post length, thread behavior, timing, hashtag usage
- TikTok: hook patterns, video length, caption strategy, audio trends
- YouTube: title, thumbnail, description, tags, search behavior
- Instagram Reels: hook, caption, hashtags, audio
- LinkedIn: format, tone, carousel/video/text behavior

Consumers:
- `write-social`
- `brief-shortform`
- SEO/AI SEO where platform search matters
- research skills that gather platform intelligence

## Acceptance Checks

- Copy cannot pass if any competitor could run it unchanged.
- Research findings include confidence and source-bias notes.
- AI SEO outputs machine-readable files or clear diffs/specs for them.
- Humanmaxxing makes writing shorter and more human without stripping specificity.
- Platform content briefs differ materially by platform.
