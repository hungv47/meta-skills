# FORSVN Brand Identity — Sunset / Forest

## Palette decision

**Deep Forest `#004700` is the only saturated color.** On dark surfaces it
lifts to Leaf `#74B36B`; warmth comes from the canvas — Warm Cream text and
the honey `#F2CE6B` logo field — never from a second accent.

- Forest Shadow `#0A120D` — the dark canvas; never pure black
- Sunset Cream `#F7F0D4` — the light canvas
- Honey `#F2CE6B` — logo field and marker wash only

## Typography

| Role | Family |
|---|---|
| Headings | Bricolage Grotesque |
| Body / UI | Be Vietnam Pro |
| Paths, counts, keycaps | JetBrains Mono |
