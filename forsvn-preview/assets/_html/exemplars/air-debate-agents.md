# Should v0 Ship Without Cloud Sync?

## Convergence

The panel converged on **local-first for v0**: every byte stays on the
operator's machine; sync is a post-v0 extension behind its own gate.

| Perspective | Position | Strongest argument |
|---|---|---|
| Velocity | ship without sync | sync doubles the surface before the wedge is proven |
| Trust | ship without sync | "your files never leave" is the wedge, not a constraint |
| Growth | add sync later | multi-device pull exists but is not the first loop |

## The dissent, preserved

> Growth's caveat: revisit after the dogfood gate passes — a second device is
> the first thing a convinced operator reaches for.
