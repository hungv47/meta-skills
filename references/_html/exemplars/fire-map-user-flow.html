Conquis onboarding

Five steps from install to first captured decision. Side panels show edge cases that block the happy path — review these before marking the flow as ship-ready.

Happy path

Median: 4 min 12 sec · target ≤ 5 min

01

Install & first launch

App opens directly to capture canvas. No splash, no tutorial.

target: < 8s cold start
02

Operator intent

Single prompt: "What are you trying to ship?" — free-text, captured to context.

conv 92% (single-screen)
03

First conversation

Captures verbal answer → renders structured decision card live.

avg 1 min 45s · 3 cards
04

Review & commit

Operator approves / edits / discards each card. Approved → working memory.

conv 88% (multi-card)
05

Hand-off

Cards exported as ready prompt for IDE / Claude / Cursor / Codex.

target: 1-click to clipboard

Edge cases

Block ship until each has a documented branch

Warn · open

Mic permission denied

iOS path requires Settings round-trip; fall back to text-only capture with a one-line nudge.

Solved

Network loss mid-capture

Local-first capture buffers in IndexedDB; sync resumes on reconnect.

Warn · open

Empty intent

Operator hits "continue" without typing — currently does nothing. Need: nudge + recent-intent recall.

Solved

Multi-language input

VN/EN detected per utterance; both render in the same card with language tags.

Solved

Long capture (> 10 min)

Cards collapse into clusters; operator can expand any cluster on review.

External app intent
