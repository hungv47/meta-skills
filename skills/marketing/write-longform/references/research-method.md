# Research Method — Write Longform

[PROCEDURE] — the evidence-gathering contract the research agent enforces. Loaded at Layer-1 research dispatch.

## The mandate: evidence before structure

The research stage is what makes a pillar a pillar instead of a long blog post. It runs FIRST and produces four things the rest of the pipeline depends on: a stress-tested thesis, an evidence ledger, the consensus baseline, and the proprietary angle.

## 1. Stress-test the thesis

Before gathering supporting evidence, find the **strongest argument against** the thesis. A thesis that can't survive its best counter-argument should be narrowed or replaced. Steel-man the opposition — the draft will address it head-on, and that's what makes the piece credible.

## 2. Build the Evidence Ledger

Every claim the piece will make needs backing:
- **Real sources** (studies, data, expert positions, documented examples) — cite the URL/title.
- **Author assertions** — tag `[author-assertion]` (a defensible claim from experience/reasoning, owned as opinion).
- **Pattern-derived** — tag `[pattern-derived]` (a generalization from observed patterns, not a cited datum).

Rate each: strong / moderate / weak. Weak evidence behind a load-bearing claim is a gap to flag.

**Absolute rule:** never invent a statistic, study, or quote. A fabricated "68% of teams..." is the single worst failure — the critic auto-FAILs the whole piece. If the number isn't real, the claim is an assertion; tag it.

## 3. Map the Consensus

Name what the first page of search already says — the obvious takes. This is mandatory and load-bearing: the piece's **Originality is scored against this baseline**. You can't judge whether a piece beats the consensus if the consensus was never named. 2–4 bullets of "here's what everyone already knows."

## 4. Find the Proprietary Angle

The reason this author can write a pillar a base model can't: a frame they own (a model, a coined term), original data (their own metrics, a survey, hard-won numbers), a contrarian-but-defended position, or specific experience. This is the seed of the Originality dimension. If the topic genuinely has no proprietary angle for this author, flag it — the honest output may be "this topic won't support a pillar; write a how-to (`write-copy`) instead."

## Source hygiene

- **No source-laundering:** don't cite a blog that itself has no source as if it were data. Trace to the primary source or tag it as an assertion.
- **Recency matters** for claims about fast-moving areas; note the date of time-sensitive evidence.
- **Disconfirming evidence is kept**, not hidden — the counter-argument section needs it.

## Output handoff

The Evidence Ledger #s are referenced by the outline (which section uses which evidence) and the draft (every prose claim maps to a #). The Consensus + Proprietary Angle flow to the critic's Originality scoring.
