# Rubric — Write Longform (7 dimensions)

[PROCEDURE] — the critic's quantitative scoring contract. Loaded at critic dispatch.

**Gate:** Total ≥36/49 AND every dimension ≥4/7 AND **Originality ≥5** (the anti-collapse floor) AND all four hard gates pass (see `agents/critic.md` § Hard Gates). Total 36–40 with all dims ≥4 and Originality ≥5 ships `DONE_WITH_CONCERNS`. Any dim <4, Originality <5, or any hard gate failing = FAIL.

## The 7 dimensions

### 1. Thesis clarity (/7)
| Band | Description |
|------|-------------|
| 6-7 | One non-obvious thesis, stated up front, defended through every section |
| 4-5 | Thesis present but stated late or only loosely defended |
| 0-3 | "A guide to X" with no argument — a survey, not a pillar |

### 2. Structural integrity (/7)
| Band | Description |
|------|-------------|
| 6-7 | Spine compresses to one line; each section earns the next; no filler; logical-dependency order |
| 4-5 | Mostly sound; one section is reorderable or thin |
| 0-3 | Interchangeable sections; listicle with no argument architecture |

### 3. Evidence quality (/7)
| Band | Description |
|------|-------------|
| 6-7 | Claims sourced or honestly tagged; specifics over adjectives; the strongest counter-argument is addressed |
| 4-5 | Evidence present; counter-argument addressed weakly OR one claim thin |
| 0-3 | Adjective-evidence; unsupported claims; counter-argument ignored |

### 4. Originality (/7) — **≥5 floor (anti-collapse gate)**
| Band | Description |
|------|-------------|
| 6-7 | A non-obvious claim / proprietary frame / original data / defended contrarian take, load-bearing in the prose; clearly beats the research agent's named Consensus baseline |
| 5 | A real original element present and developed, modestly beyond consensus — clears the floor |
| 4 | Gestures at originality but the prose mostly restates consensus — **below floor, FAIL** |
| 0-3 | Pure consensus-restatement; could appear on any competitor's blog — the write-copy collapse |

### 5. Reader-fit (/7)
| Band | Description |
|------|-------------|
| 6-7 | Altitude + vocabulary match the target reader's awareness stage; uses their VoC language |
| 4-5 | Mostly fitted; one altitude slip |
| 0-3 | Wrong audience altitude; jargon mismatch |

### 6. Prose quality (/7)
| Band | Description |
|------|-------------|
| 6-7 | Point of view, one-idea paragraphs, concrete, on-voice, no empty intro, no padding |
| 4-5 | Solid; minor AI-tells flagged for humanmaxxing |
| 0-3 | Mush, padding, throat-clearing, generic-blog voice |

### 7. Search/AEO-readiness (/7)
| Band | Description |
|------|-------------|
| 6-7 | Structure maps to intent; answer-up-front for AEO; question headings serve both reader and engine; not stuffed |
| 4-5 | Reasonable structure; AEO block missing |
| 0-3 | Keyword-stuffed, OR ignores search entirely when the brief is SEO-anchored |
| N/A | Not SEO-anchored → score the structural-clarity proxy instead; don't penalize for absent keywords |

## Scoring order (critic must follow)

Score **Originality FIRST, against the research agent's named Consensus baseline.** This prevents the most dangerous failure: a polished, on-brand, beautifully-structured piece that is pure consensus — where high marks on the other six dimensions disguise a fundamental collapse into write-copy. Originality <5 is an automatic FAIL no matter the total.
