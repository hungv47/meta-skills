# Rubric — Design Referral (6 dimensions)

[PROCEDURE] — the critic's quantitative scoring contract. Loaded at critic dispatch.

**Gate:** Total ≥30/42 AND every dimension ≥4/7 AND all four hard gates pass (see `agents/critic.md` § Hard Gates). Total 30–34 with all dims ≥4 ships `DONE_WITH_CONCERNS`. Any dim <4 or any hard gate failing = FAIL.

## The 6 dimensions

### 1. Loop-math soundness (/7)
| Band | Description |
|------|-------------|
| 6-7 | K = i × c, each input carries a labeled basis; interpretation band correct; lever each change pulls is named |
| 4-5 | K decomposed but one input's basis is thin |
| 0-3 | K asserted as a number with no i × c decomposition |

### 2. Cycle-time realism (/7)
| Band | Description |
|------|-------------|
| 6-7 | Cycle time stated; the K × cycle compounding contrast shown; collaborative-native preferred where applicable |
| 4-5 | Cycle stated but compounding effect not reasoned |
| 0-3 | Cycle ignored; a high-K-slow-cycle loop celebrated as viral |

### 3. Incentive economics (/7)
| Band | Description |
|------|-------------|
| 6-7 | CPAU computed, < CAC-displaced, margin-checked, payback stated, reward form margin-justified |
| 4-5 | CPAU < CAC but payback or margin check thin |
| 0-3 | CPAU ≥ CAC (loss-making), or no payback math, or cash-by-default unjustified |

### 4. Trigger placement (/7)
| Band | Description |
|------|-------------|
| 6-7 | Ask fires after a named value-realized product event |
| 4-5 | Trigger after value but the event is vaguely specified |
| 0-3 | Trigger on signup / before the user got value |

### 5. Mechanic falsifiability (/7)
| Band | Description |
|------|-------------|
| 6-7 | One testable i/c claim; share/invite/landing copy each pull a named lever; referee landing continuous with invite |
| 4-5 | Falsifiable claim present; one copy surface generic |
| 0-3 | "Invite friends!" generic banner; no falsifiable claim |

### 6. Fraud/abuse guard (/7)
| Band | Description |
|------|-------------|
| 6-7 | Abuse vector named + guarded; reward on qualified action; no fake scarcity |
| 4-5 | One vector guarded, another unaddressed |
| 0-3 | Fraud-blind; reward on signup; fake scarcity used |

## Scoring note

The rubric scores a **design**, not a launched loop. K and CPAU are *projected from labeled inputs*; the critic rewards a sound, falsifiable projection (every input has a basis, the math is correct, the verdict follows) — never a rosy guess. A loop whose honest computed K is a kill-candidate but whose *design and math are correct* can still score well on soundness; the loop-architect's verdict says "kill/redesign", and that honesty is the point.
