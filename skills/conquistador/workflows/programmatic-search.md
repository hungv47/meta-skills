# Programmatic search workflow

Use privately for programmatic SEO, comparison-page sets, location/category templates, or other
scaled search inventory.

1. Use `optimize-search` to verify query demand/intent, crawl/index foundations, unique page-level
   inventory, internal linking, canonical rules, and measurement.
2. Use `write-copy` to define a template whose decision-bearing content remains specific to each
   page.

Run a small manually reviewed pilot before scaling. Missing page-level evidence blocks a page. Stop
when pages are interchangeable, target the wrong intent, fail indexation after technical checks, or
produce unqualified traffic.
