# Landing-page messaging workflow

Use privately when the user needs a complete page argument, not isolated headline options.

## Required decisions

1. Use `research-positioning` when audience, costly moment, promise, mechanism, proof, or alternatives
   are not resolved.
2. Use `write-copy` for the page argument and finished section copy.
3. Use `brief-creative` for hierarchy, asset slots, responsive intent, and implementation acceptance
   criteria when a buildable brief is requested.
4. Use `improve-conversion` to review the intended decision path, first likely break, and one
   discriminating test.

## Finished package

- strategic bet and claim boundary;
- hero with audience, costly moment, promise, mechanism, and proportionate action;
- problem, mechanism/how-it-works, proof, objections, and next-step sequence;
- real or explicitly representative asset requirements;
- mobile/desktop hierarchy and state notes when implementation is in scope;
- one comprehension or conversion test with a stop/revise rule.

Never substitute decorative social proof for evidence or invent customers, metrics, compatibility,
or product behavior.

## Review

Confirm every section advances the buyer decision, proof supports the exact promise, objections are
answered specifically, and the CTA matches the visitor's likely intent.
