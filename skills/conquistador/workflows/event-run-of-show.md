# Event run-of-show workflow

Use privately when a campaign includes a live, virtual, community, partner, or in-person event.

Use `plan-campaign` to define the attendee outcome, qualified next action, segment sequence, owners,
minute cues, technical cues, dependencies, contingencies, and follow-up.

The finished cue sheet must name:

- preflight checks and owner;
- start/end times for every segment;
- host, producer, speaker, demo, and room responsibilities;
- private time cues;
- fallback for demo, screen share, speaker, attendance, and timing failures;
- privacy/recording/consent boundary;
- primary signal and follow-up owner.

Protect the attendee outcome when the schedule slips. Do not measure success from attendance alone.
