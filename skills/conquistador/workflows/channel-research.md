# Channel research workflow

Use privately when channel choice requires evidence rather than a generic recommendation.

1. Use `research-channel` to separate owned performance, current public evidence, benchmarks,
   operator constraints, and inference.
2. Use `plan-campaign` only after the channel role and first test are chosen.
3. Use the relevant creation skill for the finished native asset.

Compare audience habitat, format, proof, access, feedback speed, capacity, destination readiness,
policy/reputation risk, and decision signal. Include when not to use each channel and a revisit date.
