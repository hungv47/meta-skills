# X campaign workflow

Use privately for an X launch sequence or focused content campaign.

## Required decisions

1. Use `plan-campaign` for outcome, audience, angle, sequence, and decision rule.
2. Use `write-social` for ready-to-post copy and a useful reply bank.
3. Use `brief-creative` when media must demonstrate the mechanism or proof.
4. Use `measure-growth` to separate qualified response from impressions and engagement.

## Finished package

- one campaign bet;
- a minimum viable first post and a sequence only when each post adds new value;
- media brief grounded in real product behavior;
- replies for predictable questions and objections;
- primary signal, diagnostics, release conditions, and stop rule.

Verify current X format and link behavior when material. Do not use empty suspense, manufactured
controversy, or engagement bait. Posting and replying remain human-owned.

## Review

Confirm the opening carries a meaningful claim, the sequence compounds rather than repeats, media
shows evidence, replies advance the idea, and the CTA is proportionate to in-platform value.
