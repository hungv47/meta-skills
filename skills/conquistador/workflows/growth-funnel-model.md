# Growth funnel model workflow

Use privately when a growth or revenue target needs numeric feasibility rather than a campaign list.

1. Use `model-growth-funnel` to define units, model backward, label observed values versus planning
   assumptions, and run sensitivity.
2. Use `measure-growth` only when real baseline/cohort results must be interpreted before the model.
3. Use `plan-campaign` only after the binding constraint and feasible acquisition requirement are
   known.

Finish with the base math, downside/upside cases, capacity and unit-economics constraints, and the
smallest evidence plan. Do not reverse-engineer optimistic rates to make the target appear feasible.
