# App preview brief workflow

Use privately for a screenshot sequence, store preview, product demo, or short app interaction story.

1. Use `map-user-flow` when the source interaction and states are not already approved.
2. Use `brief-creative` to select one feature story and specify shots, motion, crop, cursor, captions,
   platform output, privacy, and acceptance.

Use real shipped UI or an explicitly labeled representative prototype. Never invent screens,
interactions, product states, notifications, data, or performance. A component-level crop is usually
clearer than a full-screen tour.
