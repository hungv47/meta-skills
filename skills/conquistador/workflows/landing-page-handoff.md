# Landing-page handoff workflow

Use privately after page messaging is approved and the user needs an implementation-ready brief.

1. Use `write-copy` for final section copy and claim boundaries.
2. Use `brief-creative` for page hierarchy, section purposes, asset slots, responsive behavior,
   interaction states, and acceptance criteria.
3. Use `improve-conversion` to verify the buyer decision path and first discriminating test.

Every section must advance the same audience, costly moment, promise, mechanism, proof, objection, and
action. Ground visuals in real shipped UI or label them representative. Specify mobile/desktop
hierarchy, loading/empty/error states where relevant, accessibility, and testable implementation
acceptance. Do not invent product behavior or customer proof.
