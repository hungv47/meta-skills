# Fixture: results review

## Request

“The launch post got impressions but almost no trials. Here are the post, page, and numbers. What
should we do?”

## Expected behavior

- Distinguish reach, attention, comprehension, belief, motivation, friction, and delivered value.
- Use the supplied evidence; identify missing data separately from zero.
- Return keep, drop, and one controlled test with a decision rule.
- Save one bounded learning only when the evidence supports it.
- Avoid treating impressions or a single cycle as proof of strategy.
