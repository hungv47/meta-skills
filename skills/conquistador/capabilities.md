# Compact capability map

Use this map privately. Select the smallest capability sequence that produces the requested outcome.
Skip a capability when existing context already supplies its decision.

| User outcome | Primary capability | Add only when needed | Required finish |
|---|---|---|---|
| Understand a market, customer, or position | `research-positioning` | `create-brand` for a durable identity decision | Evidence-backed position and decision implications |
| Launch a product | `plan-campaign` | `research-positioning`, then `write-social`, `write-copy`, or `brief-creative` for named assets | Campaign spine, ready assets, run of show, measurement |
| Build a growth campaign | `plan-campaign` | `write-copy`, `write-social`, `optimize-search`, `measure-growth` | Ranked bets, executable assets, stop/scale rules |
| Create a page or campaign asset | `write-copy` or `brief-creative` | `research-positioning` if the audience or promise is unresolved | Finished copy or implementation-ready brief |
| Create channel content | `write-social` | `research-positioning` for an unproven angle | Ready-to-post native work and reply plan |
| Improve a page, campaign, or funnel | `improve-conversion` | `measure-growth` when results exist; relevant creation skill for the revision | Diagnosis, revised work, one discriminating test |
| Improve search or answer visibility | `optimize-search` | `write-copy` for the revised page | Technical/content diagnosis and prioritized correction |
| Learn from results | `measure-growth` | `improve-conversion` for the next test | Keep/drop/test decision and bounded learning |
| Create or revise Vietnamese work | `polish-vietnamese` | The outcome skill for strategy or channel requirements | Natural Vietnamese with preserved factual strength |
| Establish a sustainable brand | `create-brand` | `research-positioning` for missing market evidence | Usable brand foundation, voice rules, and applications |
| Map a product journey or feature | `map-user-flow` | `research-positioning` when audience/job evidence is unresolved | Screens, transitions, state coverage, recovery, validation |
| Specify a product interface | `brief-product-ui` | `map-user-flow` when the source flow is absent or incomplete | Traceable component, token, state, accessibility, and handoff spec |
| Model a growth or revenue target | `model-growth-funnel` | `measure-growth` for observed baselines; `plan-campaign` after the constraint is known | Inspectable model, sensitivity, constraints, and evidence plan |
| Create or evaluate paid media | `create-paid-campaign` | `research-positioning` for an unresolved segment/offer; `brief-creative` for production | Finished ads, creative direction, budget/test, decision rule |
| Create direct outreach | `write-outreach` | `research-positioning` for an unresolved segment or proof boundary | Signal-led sequence, replies, compliance, and qualified-response plan |
| Write a substantive long-form piece | `write-longform` | `research-positioning` for missing evidence; `polish-vietnamese` for Vietnamese | Defensible thesis, traceable evidence, objections, finished draft |
| Create short-form video | `create-shortform` | `plan-campaign` for a broader campaign decision | Evidence boundary, hero, storyboard, true recuts, production, learning |
| Research or choose a channel | `research-channel` | `plan-campaign` after the channel role is chosen | Typed evidence, fit comparison, focused recommendation, first test |
| Resolve a contested or consequential decision | `debate-agents` | `knowledge-review` when sources conflict; `research-positioning` for market context | Chosen position, explicit criteria, and the evidence that would reverse it |
| Audit the facts behind a claim | `knowledge-review` | `debate-agents` when positions conflict | Authority/freshness/uncertainty table, contradiction matrix, surviving unknowns and recheck trigger |

For multi-stage work, preserve one decision spine across every capability:

1. audience and costly moment;
2. credible promise and mechanism;
3. proof and main objection;
4. chosen action;
5. primary signal and decision date.

Do not narrate the map. Return one coherent package rather than separate skill reports.
