"Gated" is two gates: an **operator-approval gate** between plan and apply — the planner's full plan (service interface + caller list + order) is shown and `Apply this migration? [y/N]` is asked; no code is edited until `y`, and `N` ships the plan as a `DONE` plan-only artifact — plus the **5-golden-rules safety contract** gating every caller swap. **4-agent shape:** scanner (finds repeated mechanics, classifies the shared *how* vs caller-resident *why/when*, enumerates callers) → planner (designs the service interface — explicit data params, structured returns, no caller-branching flags — + the ordered per-caller migration plan) → migration (applies the approved plan one caller at a time, verifying after each, stopping on first red) → critic (8-gate review). Layer 1 scanner; Layer 2 sequential planner → migration; Layer 3 critic. Single-agent fallback for ≤3-caller scopes / `--fast`. **8 Critical Gates:** the 5 Golden Rules inherited verbatim from clean-code (preserve behavior / small incremental steps / check conventions first / verify after each change / rollback awareness — extract-service edits code, so it carries the same safety contract) + 3 extract-service-specific — **G6 Extraction threshold** (do not extract for <2 real callers; 1 caller → `NEEDS_CONTEXT`, premature-abstraction guard), **G7 Two-layer purity** (the service holds only the shared *how*; orchestration/domain *why/when* stays in callers; a param that carries a *branch* rather than *data* is a layer leak), **G8 Baseline-green** (pre-existing test/build failure → `BLOCKED`). All 8 gates + the operator-approval gate fire under `--fast` (safety supersedes mode-resolver downgrade). The critic enumerates the 8 gates + 4 service-design dimensions (explicit params / structured returns / composability / no silent drift normalization) and 5 Hard Fails (behavior change in a caller / domain logic in the service / a caller migrated without verification / batched callers / extraction at one caller). **Drift is reported, not normalized** — when the scan finds callers that have silently diverged, the default is to preserve each caller's current behavior exactly; a drift fix ships as a separate, flagged, operator-approved change, never folded into the migration. `budget: standard` (between clean-code's `deep` and IDEA-3's original `fast` suggestion). Provenance frontmatter per D8.
